# Chat Kemer — нативный мод для LeviLauncher

Целевая платформа: Android ARM64 (`arm64-v8a`). Формат пакета: `ChatKemer.levipack`, внутри которого находится `libChatKemer.so`.

## Реализовано в исходниках

- Регистрация модуля **Chat Kemer** через Preloader Android 0.2.3.
- Шесть HUD-кнопок с чёрно-белым оформлением.
- Настройка масштаба кнопок (0,6–1,8) и прозрачности (20–100%) в Mod Menu.
- При ошибке регистрации одной из кнопок выполняется откат частично зарегистрированных кнопок.

## Пока не реализовано

- Перетаскивание кнопок и сохранение их отдельных координат.
- Редактирование текста каждой кнопки из меню.
- Отправка команд или сообщений в игровой чат при нажатии: сейчас обработчик только записывает событие в лог.

Эти функции не следует считать готовыми. Они требуют подтверждённого публичного API LeviLauncher/Preloader; приватные адреса и неподтверждённые вызовы не используются.

## Сборка

Требуются Android NDK, CMake 3.22+, Git и ZIP:

```bash
export ANDROID_NDK_HOME=/path/to/android-ndk
./scripts/build-android.sh
```

Результат локальной сборки: `dist/arm64-v8a/ChatKemer.levipack`.

GitHub Actions автоматически собирает ARM64-пакет при обновлении ветки `main`. Успешный CI подтверждает компиляцию и проверку структуры/архитектуры пакета, но не заменяет запуск и тестирование на устройстве.

## Совместимость

Манифест указывает Minecraft Bedrock **1.26.60.4** и предназначен для LeviLauncher **1.6.1**. Фактическая совместимость и отсутствие вылетов должны быть проверены на устройстве.

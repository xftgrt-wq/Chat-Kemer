# Chat Kemer — проект нативного мода LeviLauncher

Целевая платформа: Android ARM64 (`arm64-v8a`). Формат результата: `libChatKemer.so` внутри архива `ChatKemer.levipack`.

## Структура готового .levipack

```text
manifest.json
libChatKemer.so
config/config.json
config/config.schema.json
```

Архив должен содержать эти файлы в корне, без дополнительной папки `ChatKemer/`.

## Сборка

Нужны Android NDK r27c, CMake 3.22+, Git и ZIP. На Linux/macOS:

```bash
export ANDROID_NDK_HOME=/path/to/android-ndk
./scripts/build-android.sh
```

Результат: `dist/arm64-v8a/ChatKemer.levipack`.

Также есть GitHub Actions workflow `.github/workflows/android-arm64.yml`. Workflow можно запустить вручную; собранный `.levipack` появится в Artifacts. Локальный и CI-сценарии используют один скрипт `scripts/build-android.sh`.

## Текущий статус функциональности

Это исходный проект, а не собранный и протестированный мод. В коде регистрируются модуль и шесть HUD-кнопок. Для кнопок добавлены элементы `HudEditorElement` через публичный API Preloader: их расположение предназначено для настройки в HUD Editor LeviLauncher; сохранение координат зависит от поведения самого лаунчера и ещё требует проверки на устройстве. Настройка размера и прозрачности доступна в Mod Menu и обновляет оформление кнопок. Фактическое перемещение и сохранение координат нужно проверить на устройстве. Нажатия пока только записывают выбранную команду в лог: документированного публичного API отправки произвольной строки в игровой чат в используемом SDK не найдено, поэтому команды ещё не выполняются.

Проверка пакета дополнительно проверяет ELF-заголовок библиотеки: 64-bit little-endian, ET_DYN и EM_AARCH64. Это подтверждает архитектуру файла, но не гарантирует совместимость во время запуска.

Не устанавливай пакет как готовый мод до успешной сборки и проверки на конкретной версии LeviLauncher/Minecraft. SDK закреплён на Preloader Android 0.2.3. В этой среде Android NDK отсутствует, поэтому файл `libChatKemer.so` здесь не собран. Не выдавай исходный архив за готовый игровой мод.
